# Spotify_clone
🎵 Spotify Clone  A front-end clone of Spotify built only with HTML &amp; CSS.  Highlights:  🎧 Clean and modern UI inspired by Spotify  📂 Home, playlists, and music player sections  📱 Fully responsive design (desktop &amp; mobile)  🎨 Focus on layout, styling, and usability  Goal: Practice and showcase front-end skills using only HTML &amp; CSS.
